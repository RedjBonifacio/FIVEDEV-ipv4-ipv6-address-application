# System Requirements

## Functional Requirements

- Retrieve the public IP address.
- Display the IP address clearly.
- Display additional network information provided by the API.
- Handle cases where some information is unavailable.

## Non-Functional Requirements

- The application should be simple to use.
- The output should be clear and readable.
- The application should handle API errors properly.
- The application should use a REST API and process JSON data.
