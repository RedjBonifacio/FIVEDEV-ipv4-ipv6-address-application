# IPv4/IPv6 Address Application

A Python application that uses public REST APIs to retrieve and display the computer's current IPv4 and IPv6 address information.

## Objectives
- Retrieve the public IPv4 address.
- Retrieve the public IPv6 address when available.
- Display IP information clearly.
- Display additional network information when supported by the API.
