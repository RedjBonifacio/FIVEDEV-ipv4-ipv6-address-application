# API Research

## Selected API
ipapi.co

## Purpose
The API retrieves the computer's public IP address and related network information.

## Information to Retrieve
- Public IP address
- Country and country code
- City and region
- Timezone
- ASN
- Organization or ISP

## Reason for Selection
ipapi.co was selected because it provides a simple HTTPS REST API, supports JSON responses, and can return IP and related network information. It is suitable for a Python application.

## API Endpoint
https://ipapi.co/json/

## Response Format
JSON
